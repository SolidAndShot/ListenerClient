# 监听器客户端 Mod 使用教程

## 1. 安装

1. 准备 Minecraft 26.2、Fabric Loader 0.19.3、Fabric API 0.153.0+26.2 和 Java 25。
2. 将 `listenerclient-1.0.0.jar` 放入客户端 `.minecraft/mods`。
3. 将服务端 Listener 插件更新到包含 `ClientBridge` 的版本，并重启服务端和客户端。

客户端 Mod 是可选组件。不安装它时，服务端插件的 Bukkit 事件监听器仍然正常工作；安装并连接后，客户端独有事件才会出现。

## 2.5 图形化控制台

进入游戏后按 **K** 打开客户端控制台。这里不需要编辑配置文件，就可以切换四类事件上报：输入、鼠标、位置与注视、状态事件。点击“保存设置”后配置保存在：

```text
.minecraft/config/listenerclient.properties
```

界面顶部会显示是否已连接以及是否完成 Listener 握手；按 K 或点击“关闭”退出。服务端也能在规则动作中打开控制台：

```yaml
actions:
  - type: client_screen
    value: dashboard
```

这四个开关只影响客户端向服务端发送的事件，不会改变服务端 Listener 规则。

## 2. 检查连接

客户端进入服务器后，Mod 会在 `listener:main` 通道发送 HELLO。服务端确认后返回 HELLO_ACK，客户端才开始上报事件。服务端可使用 `client_connect` 规则测试：

```yaml
listeners:
  client_join_notice:
    event: client_connect
    actions:
      - type: message
        value: "&a客户端监听器已连接，版本 %mod_version%"
```

## 3. 客户端事件

客户端事件会由服务端自动加上 `client_` 前缀，因此配置中使用以下事件名：

```text
client_connect
client_screen_open / client_screen_close
client_keyboard_key_pressed / client_keyboard_key_released
client_keyboard_char_typed
client_mouse_button_clicked / client_mouse_button_released
client_mouse_scrolled / client_mouse_moved
client_dimension_entered
client_position_changed
client_start_looking_at_block / client_stop_looking_at_block
client_start_looking_at_entity / client_stop_looking_at_entity
client_started_running / client_stopped_running
client_started_swimming / client_stopped_swimming
client_started_burning / client_stopped_burning
client_started_drowning / client_stopped_drowning
client_started_freezing / client_stopped_freezing / client_fully_frozen
client_start_touching_fluid / client_stop_touching_fluid
client_player_death
client_damage_taken
client_experience_changed
client_weather_changed
client_tick
```

例如，当玩家打开任意客户端屏幕时执行动作：

```yaml
listeners:
  menu_open:
    event: client_screen_open
    filters:
      screen_contains: "Screen"
    actions:
      - type: client_action
        value: "message|打开了客户端界面：%screen%"
```

事件字段会作为变量提供，例如 `screen`、`key_keycode`、`button`、`mouse_pos_x`、`dimension_key`、`damage_amount` 和 `target`。

## 4. 服务端下发客户端动作

只有通过 Listener 规则配置的动作才会发送给客户端；客户端对未知动作会安全忽略。可用动作：

```yaml
actions:
  - type: client_message
    value: "欢迎使用客户端监听器"
  - type: client_overlay
    value: "ActionBar 文本"
  - type: client_screen
    value: "inventory"
  - type: client_screen
    value: "close"
  - type: client_sound
    value: "minecraft:ui.button.click,1.0,1.0"
```

客户端动作只影响当前玩家，不执行任意 JavaScript 或任意系统命令。`client_tick` 每秒最多上报一次；位置、鼠标移动等事件仍可能频繁触发，请用过滤器限制范围。

## 5. 常见问题

- **没有 `client_connect`：** 检查双方都使用 `listener:main`，确认客户端装有 Fabric API 和 Mod，并查看服务端是否启用了 Listener 插件。
- **服务端有连接但没有事件：** 只有客户端收到 `HELLO_ACK(accepted=true)` 后才会上报；检查服务端日志中的协议版本。
- **界面事件重复：** 不要同时配置 `client_screen_open` 和对同一状态的 `client_tick` 规则，后者是低频心跳而非边沿事件。
- **按钮或音效不执行：** 客户端动作是白名单功能，未知动作会忽略；使用上面列出的动作名称。
